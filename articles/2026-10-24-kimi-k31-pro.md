# 月之暗面官宣 Kimi K3.1 Pro：约 3T 开权重、1M 上下文——Arena 暗测方向坐实了

![Kimi K3.1 Pro 官网配图](./assets/2026-10-24-kimi-k31-pro/kimi-k31-pro-hero.jpg)

*图：月之暗面 [Kimi K3.1 Pro 技术博客](https://www.kimi.ai/blog/kimi-k3-1-pro) 官方营销图。事实以该博客为准。*

2026 年 10 月，月之暗面（Moonshot AI）在官网正式介绍 **Kimi K3.1 Pro**：自称是新系列 K3.1 的首款模型、迄今最强的约 **3T 级开权重量级**，带 **100 万 token** 上下文；同日还放出更快的 **Kimi K3.1 Pro Highspeed**（博客称速度约为 Pro 的 **2–3 倍**）。产品侧今日起可在 Kimi.ai、Kimi Work、Kimi Code 与 Kimi API 使用；**完整权重预计在 11 月 4 日前放出**。

此前 Arena 上匿名模型 Kibitz 被社群押为 K3.1——那是预发布信号。**这篇主线是正式产品官宣**：暗测方向坐实了，但下面只写博客可核的数字与口径，不复读猜测稿。

**一句话说清：写代码、跑长任务、做 3D / 金融 agent 的人，多了一个「能上产品、且承诺开权重」的旗舰档选择；普通人则可在 App / 网页直接试，不必等本地权重。**

---

## 1. 普通人 / 开发者立刻懂：值不值得点开

对**普通用户**：Kimi 产品里多了一档更强的 Pro，以及更跟手的 Highspeed。博客强调编码、3D 创作、金融研究等 agent 能力有实质提升——若你日常用 Kimi 写网页、改项目、查资料，换一档模型就能感知差异，不必先懂「3T」「开权重」。

对**开发者 / agent 栈选型**：

- **今天就能接**：API 模型名 `kimi-k3.1-pro` / `kimi-k3.1-pro-highspeed`；Kimi Code 可用 `/model` 切换；Kimi Work 需桌面端 ≥ 3.1.0。
- **开权重有日程**：完整权重 **by Nov 4**（2026）——适合盯「能自托管 / 能复现」的团队记日历，而不是当成已经可下载的权重包。
- **企业默认关**：Kimi Enterprise 管理员可为组织开启，**上线时默认关闭**。

一句话：热度不只在榜单，而在「产品已开 + 权重有排期」这条开放智能叙事。

## 3. 冷静段：官宣不等于「已碾压一切」

1. **基准是官网自报，评测条件要看脚注。**  
   Terminal-Bench 4.0 的 65.7% 等数字来自 Moonshot 技术博客；Kimi 侧多用 Claude-Code harness、reasoning effort 设为 max 等（见文末脚注）。对比表里的对手分数，博客写明部分取自对方博文或官方榜——**可引用，勿外推成「全面第一」**。它对 Opus 5.5 仍是「略低一截」（66.4% vs 65.7%）。

2. **完整权重尚未放出。**  
   「by Nov 4」是排期，不是「今天就能 `huggingface-cli download`」。在权重落地、许可与推理脚本公开前，**开源社区复现与第三方安全审计都还谈不上完成时**。产品可用 ≠ 权重已开。

3. **开源版剔除攻防相关数据，是能力取舍，不是「模型不会碰安全」。**  
   90.5%→81.0% 说明数据清理有效压低了内部利用基准表现；博客同时承认：通用编码与长程调试变强后，**能力仍会部分泛化到 cyber 任务**。勿写成「开源版已无攻击面」或「已解决所有滥用风险」——这是披露的控制措施与原则，不是免责金牌。

4. **勿吹成通吃所有场景。**  
   博客重点展示编码、3D、金融等；Highspeed 是速度档，不是「另一个更强智商档」。企业默认关闭、硬件与配额、真实业务集表现，都要以你自己的试用为准。此前 Kibitz 猜测稿里的非官方 Minecraft / 成本叙事，**不要搬进这篇当采购依据**。

**一句话：K3.1 Pro 把「可产品化的旗舰」和「约 3T 开权重承诺」绑在同一天官宣，方向清楚、数字可核；但榜上自报、权重待放、安全相关数据有意剔除——兴奋可以，选型请等权重与自测。**

## 4. 读者行动

1. 想先用：打开 [kimi.ai](https://www.kimi.ai) / 更新 Kimi App；写代码可在 Kimi Code 用 `/model` 选 K3.1 Pro；要跟手可选 Highspeed。  
2. 要接 API：到 Kimi API Platform 选 `kimi-k3.1-pro` 或 `kimi-k3.1-pro-highspeed`；需要可开 Zero Data Retention。  
3. 盯开权重：把 **2026-11-04** 记进日历，以官网实际释出页为准，勿提前默认镜像可用。  
4. 企业管理员：确认是否要为组织**手动开启**（默认关）。  
5. 对比旧猜测：可以把这篇与仓内 [Arena Kibitz 预发布稿](./2026-10-22-arena-kibitz-kimi-k31.md) 对照——信号 vs 官宣，分两篇看更清楚。
