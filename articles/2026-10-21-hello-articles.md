# 文章助手 · GitHub 发布链路试跑

这是一篇试跑稿，用来确认「写稿 → 推到 GitHub」这条链路能走通。

## 为什么放 GitHub

文章先落在公开仓库里，版本清楚、方便改、也方便以后同步到别的平台。对阿丰来说，GitHub 是最先打通的发布口。

## 仓库怎么用

- 每篇文章是一个 Markdown 文件，放在 `articles/` 目录
- 文件名带日期，方便排序
- 索引写在 `articles/README.md`

## 后续还会同步到哪里

计划还会同步到小红书、人人都是产品经理、微信公众号。那些渠道还没在这条试跑里真正发出去，只是把方向先写清楚。
