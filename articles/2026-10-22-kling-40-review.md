# 可灵 Kling 4.0 评测：30 秒长镜头、10 关键帧，短剧该不该立刻换引擎？

> 资料核对：2026-10-22（北京时间 / Asia/Shanghai）。本稿是**产品评测**，不是上线简讯。结论综合官方规格与多家第三方实测；分数与主观判断均标注来源。凡写「还没核到」的条目，请勿当已交付能力写进项目计划。

## 一句话结论

**Kling 4.0（2026-10-15 全量）值得短剧 / 漫剧 / 广告文戏创作者立刻重测**：单次原生最长约 30 秒、最多 10 关键帧、最多 15 项全能参考、立体声与多语种口型，把「一次生成 = 一个场景单元」从口号推近了一步。  
但到本稿日为止，**Artificial Analysis 公开榜上还没有 Kling 4.0 条目**（榜上仍是 2 月的 Kling 3.0）；独立实测普遍肯定运动与对白，也反复碰到「点名一镜到底仍被切镜」「无引导打斗脚底打滑」；**4K / 10-bit HDR、续拍到约 2 分钟、企业 API 刊例价**官方多为「将支持 / 即将开放」。  
**选型别站队**：文戏特写与带分镜的可控长镜头优先试可灵；纯文本高速格斗、复杂多切镜剧本，多家实测仍更倾向 Seedance 2.5；要公开 Elo 与已公布 API 单价，MiniMax H3 / Wan 3.0 证据更全。

---

## 适用谁、不适用谁

| 更适合上 Kling 4.0 | 建议先别押宝 / 换引擎 |
| --- | --- |
| 需要 **15–30 秒连续运镜** 的追逐、跟拍、情绪铺陈 | 本周就要 **稳定 4K + 10-bit HDR 母带**（官方仍是「将支持」） |
| **写实对白 / 方言口音 / 声音克隆** 中近景（多家实测称口型与人声干净） | **纯文字**出高速格斗、复杂物理碰撞（无关键帧 / 无参考视频时易「溜冰」、瞬移） |
| 已有分镜图，要用 **多关键帧** 锁机位与动作节点 | 既要多关键帧、又要同镜开口说话 + Elements（第三方称多关键帧模式会关对白与主体） |
| 商品 / 角色 **创意复刻**（参考视频换人换品） | 要 **480p 廉价草稿档** 或 **已公开的开发者 API 刊例**（可灵侧证据薄） |
| 中文内容、已在可灵工作流里的短剧团队 | 必须先看公开榜再采购——**4.0 尚未入榜** |

## 我们在评什么（版本与口径）

- **完整版 Kling 4.0**：快手 IR 写明 **2026-10-15** 正式上线（IR 稿发布页日期 10-17）。  
- **Flash**：约 9-28 起给部分高阶订阅尝鲜；常见上限约 **720p、最长约 20 秒**；首周英文社区大量体感其实测的是 Flash，**不能直接当完整版定论**（SLOP TV 汇总，2026-10-19）。  
- 官方主打能力（IR / The Decoder 转述）：单次最长约 **30 秒**；关键帧最多 **10**；全能参考合计最多 **15**（图≤10、视频≤5 且合计约 30 秒、主体≤7）；提示词约 **8000 tokens**；立体声 + 多语种口型；接入 MCP / CLI；API「即将」对企业与开发者开放。

## 分项：全网实测怎么说

### 画质与成片观感

- 优设网「数字生命卡兹克」烧积分实测（约 10 月中旬）：城市追逐、马戏团长镜头、花滑、篮球等，认为大动态与细节（如撞倒纸箱形变）比上代更像「能交差的镜头」，并点名期待尚未上线的 10-bit 4K HDR。  
- DXBuilder 工程评测（2026-10-17，评测方为竞品多引擎平台创始人，**利益相关，分数仅作他家口径**）：写实文戏对白打 **9.2/10**，动画角色一致 **8.6/10**；同时写明首发实际多为 **720p / 1080p**，规格表上的原生 4K / 10-bit **当时未开**。  
- Tom's Guide（产品向综述）强调更稳的跟拍 / 环绕与角色一致性，语气偏乐观，**偏厂商愿景转述，宜当背景而非硬证据**。

### 运动与物理

- 共识偏正面：电梯打戏、追逐、花滑等「动作链条可读」——卡兹克、Neo Dong（DEV / ReelDance，约 10-16）都写到跟拍与重心比以往更说得通。  
- 共识偏负面：**无关键帧 / 无参考视频** 的近身格斗，DXBuilder 明确写「脚底溜冰（ice-skating）、穿模、切镜后站位瞬移」；纯文格斗约 **4.5/10**，换成武术参考视频 V2V 后升到约 **8.4/10**。  
- The Decoder（2026-10-19）看官方对比样片：相对 Wan 3.0、Seedance 2.5，可灵「站得住但没有明显甩开」，尤其逻辑分镜、物理与对白自然度。

### 可控性（关键帧 / 全能参考）

- **10 关键帧**被多家当成本代最实用升级：用分镜图锁节点，比纯堆长提示词稳。  
- **坑（DXBuilder）**：开 Multi-Keyframe 后，**Elements、人声对白、BGM 会被关掉**，只剩环境音一类——动作戏要开口，得改 Omni 参考或后期配音。  
- 全能参考 + 创意复刻：卡兹克用指环王运镜换场景换角色、三视图换人等案例，说明「参考视频控运镜 / 换品」是可灵强项场景。  
- Omni 与 Keyframes **官方指南口径是同一任务不能混用**（TopAI.one 对照官方文档，核对日约 10-18）——规划工作流时当成硬约束。

### 口型、方言与音频

- 多家独立 / 半独立体感：Flash 与完整版都有人称赞多语种配音与口型（Reddit u/Jack_P_1337、Lovelady、Theoretically Media 等，见 SLOP TV 汇总）。  
- DXBuilder：英音 / 美音、京味与台湾腔普通话长句「无金属颤音（wobble）」，喉部肌肉牵动可见——**这是本稿最敢写的「文戏王牌」判断，但仍是第三方一手测试，不是榜单**。  
- 反面：Flash 用户抱怨**擅自加 BGM**、多角色背景路人乱入（Jack_P / Lovelady）。完整版是否完全修好，公开记录仍短。

### 时长、一镜到底与续拍

- **30 秒原生**：官方确认；卡兹克、Neo Dong 都跑出可用长镜头。  
- **「30 秒 ≠ 保证一镜到底」**：Neo Dong 写 long connected shot 可能，但时长不保证无切；Flash 侧 Jack_P 称「怎么提示都爱切镜且关不掉多镜头」。这是首周争议主轴（SLOP TV）。  
- **续拍至约 2 分钟**：官方「后续 / soon」，**本稿标为未核交付**。

### 价格与配额

- 快手 IR **未公布** C 端积分单价。  
- 实测口径（上线夜观察，**非官方刊例、可能已变**）：  
  - Neo Dong / 卡兹克：**1080p × 30s ≈ 450 积分**；Flash **720p × 20s ≈ 120 积分**。  
  - 卡兹克按会员价粗算约 **¥16 / 条 1080p 30s**、**¥9 档 720p**（粗算，受套餐折扣影响）。  
  - kie.ai 等转述约 **1080p 15 积分/秒、720p 10 积分/秒**（与 450 对得上）。  
- 实操建议（多家一致）：**Flash 打样 → 完整版收片**，看的是「出一条能进时间线的废片成本」，不是单次标价。

### API 与自动化

- 官方：MCP / CLI 已接；**企业 / 开发者 API「即将开放」**。  
- DXBuilder 曾写第三方 API 约 **10-21** 起陆续——到本稿日请以控制台实况为准，**不要写死已 GA**。  
- OrcaRouter（2026-10-22）：对比 MiniMax H3 时强调 Kling 4.0 **无公开 API 刊例、无独立榜分**；H3 有 AA 分数与 $0.08/秒（768p）一类可核价格。

## 竞品怎么摆（能力 vs 证据）

下列为**规格 + 公开榜 / 第三方口径**对照，不是本稿自测排名。Artificial Analysis 数字以 **AA-Video-T2V v2.1** 页面与 OrcaRouter 2026-10-22 转述为准；**榜上没有 Kling 4.0**。

| 维度 | Kling 4.0 | Seedance 2.5 | Wan 3.0 | MiniMax H3 | Runway Gen-4.5 | Google Veo 3.1 |
| --- | --- | --- | --- | --- | --- | --- |
| 单次时长（常见） | 约 3–30s | 最长约 30s | 最长约 30s | 约 4–15s | API 常见约 2–10s | 常见 4/6/8s |
| 公开 T2V Elo（有音频） | **4.0 未上榜**；Kling 3.0 1080p 为锚点 1000 | 约 1158（并列前列集群） | 约 **1175 领先**（样本数千） | 约 1158（768p） | 历史强，当前榜位随版本变 | 约 960 段（Veo 3.1 一行） |
| 可控性亮点 | 最多 10 关键帧；15 项 Omni | 复杂多切镜 / 物理口碑强（第三方） | 多语种口型 + 性价比（第三方） | 图/视/音统一上下文；可下载权重（许可有区域限制） | 后期格式、多模型 API | Google 生态内短片 + 原生音频 |

**读表方式**：要「这周就能按秒报价、按 Elo 汇报」→ 先看 H3 / Wan；要「30 秒 + 多关键帧导演感」→ 只有可灵 4.0 规格对得上，但你买的是**尚未被公开榜校准**的能力。

Sora：多家 2026 年工具盘点写明 App / API 已退出主流可选池，对比时不必再把 Sora 当默认竞品。

## 还没核到的（写进 PRD 前再查一遍）

1. **Artificial Analysis（及同类）对 Kling 4.0 的 Elo** —— 截至 2026-10-22 未见条目。  
2. **官方 C 端积分价目表、企业 API 刊例与 SLA** —— 仅有实测观察值与「即将开放」。  
3. **4K / 10-bit HDR / 21:9 是否已对你的账号稳定开放** —— IR 用「将支持」；DXBuilder 10-17 称首发未开 4K/HDR。  
4. **续拍多次至约 2 分钟** —— 路线图，非本稿可核交付。  
5. **完整版是否已修好 Flash 的「强行切镜 / 乱加 BGM」** —— 完整版样本仍少，结论勿外推。  
6. **商用授权细则** —— 英文条款讨论里出现过「书面许可 / 需标注」类提醒（第三方工具文）；签约前读你账号对应服务条款，本稿不做法务结论。

## 我怎么用（可执行工作流）

1. **Flash（或低成本档）** 跑构图、运动方向、要不要切镜。  
2. 定稿镜头用 **完整版 + 参考图/视频**；动作戏优先喂武术 / 运镜参考，少赌纯文。  
3. 需要精确机位 → **多关键帧**；需要说话 → **别开多关键帧**，或后期配音。  
4. 项目若卡 API、HDR、公开榜——**并行留 Seedance / Wan / H3 备份**，别单线程赌可灵路线图。
